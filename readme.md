🌍 Tour Booking System (MERN Stack)

A full-stack web application that allows users to explore, book, and manage tour packages. Built using the MongoDB, Express.js, React, and Node.js stack.

🚀 Features
👤 User Authentication (Login/Register using JWT)
🌐 Browse available tour packages
📄 View detailed tour information
🧾 Book tours and manage bookings
📊 View booking history
🛠️ Admin panel to:
Add / Update / Delete tours
Manage user bookings
⚡ Responsive UI
🔗 RESTful API integration
🛠️ Tech Stack
Frontend: React, HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MongoDB
Authentication: JWT (JSON Web Tokens)
📂 Project Structure
tour-booking-system/
│
├── frontend/        # React frontend
├── backend/         # Node.js + Express backend
├── models/          # Database schemas
├── routes/          # API routes
├── controllers/     # Business logic
└── README.md
⚙️ Installation & Setup
1️⃣ Clone the repository
git clone https://github.com/your-username/tour-booking-system.git
cd tour-booking-system
2️⃣ Setup Backend
cd backend
npm install
npm start
3️⃣ Setup Frontend
cd frontend
npm install
npm start
🔐 Environment Variables

Create a .env file in the backend folder and add:

MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=5000
